## النشر على GitHub Pages
1. ريبو جديد، وارفع **اللي جوه** الفولدر ده (`index.html` و`style.css` و`script.js` و`assets`) في أول الريبو.
2. Settings ← Pages ← Deploy from a branch ← `main` / root ← Save.
3. الموقع على: `https://USERNAME.github.io/اسم-الريبو/`
